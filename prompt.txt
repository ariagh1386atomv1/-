پروژه: ساخت قالب وردپرس «دارونیک» + Aria Builder

1. هدف کلی پروژه

ما در حال ساخت یک پروژه تمرینی/تحقیقاتی برای توسعه یک محصول تجاری حرفه‌ای وردپرس هستیم.

نام موقت قالب:

**دارونیک — Daroonik**

هدف این است که یک قالب فروشگاهی مدرن برای WordPress + WooCommerce بسازیم که از نظر تجربه کاربری و ظاهر، در نسخه اول بسیار نزدیک به قالب **Daroochi** باشد، اما از نظر قابلیت ویرایش، انعطاف‌پذیری و اتصال عمیق به WordPress/WooCommerce بسیار قدرتمندتر باشد.

این پروژه فعلاً فقط روی **Localhost** اجرا و تست می‌شود و بعد از تکمیل و پایدار شدن برای انتشار تجاری آماده خواهد شد.

2. فلسفه اصلی پروژه

ما نمی‌خواهیم یک Headless Theme ساده بسازیم.

همچنین نمی‌خواهیم صرفاً یک قالب معمولی مثل WoodMart بسازیم.

هدف ما ترکیب این سه ایده است:

Daroochi

برای:

- طراحی مدرن
- ساختار صفحات
- ظاهر فروشگاهی
- بخش‌های جذاب
- کارت‌ها
- انیمیشن‌ها
- UX
- Layout

WoodMart

برای:

- سازگاری عمیق با WordPress
- WooCommerce
- Theme Settings
- Customization
- Demo Import
- Header/Footer
- Typography
- Colors
- Menus
- Site Identity
- WooCommerce integration
- Compatibility با اکوسیستم WordPress

Elementor / Elementor Pro

برای:

- تجربه Visual Builder
- Widget System
- Container
- Responsive Controls
- Content Controls
- Style Controls
- Advanced Controls
- Dynamic Content
- Drag &amp; Drop
- Live Editing

اما:

**Aria Builder باید سیستم اختصاصی خودمان باشد.**

4. Aria Builder

ما یک Visual Builder اختصاصی با نام:

**Aria Builder**

می‌سازیم.

این Builder باید از نظر تجربه کاربری شبیه Elementor باشد اما UI آن:

- مدرن‌تر
- سریع‌تر
- نرم‌تر
- تمیزتر
- ساده‌تر
- حرفه‌ای‌تر
- مناسب RTL
- مناسب فارسی

باشد.

وقتی کاربر وارد یک برگه WordPress می‌شود:

```text
Pages
→ Edit
→ Edit with Aria Builder

```

یا در بالای صفحه:

```text
ویرایش با Aria Builder

```

را ببیند.

با کلیک روی آن، Builder باز شود.

5. رفتار Builder

صفحه باید واقعاً قابل ویرایش باشد.

مثلاً اگر صفحه دارای Hero باشد:

```text
Hero
├── Container
├── Heading
├── Text
├── Button
└── Image

```

کاربر روی Heading کلیک کند.

Aria Builder دقیقاً همان Heading واقعی را انتخاب کند.

اگر متن:

«بهترین محصولات مراقبت از پوست»

باشد، همان متن را در پنل ویرایش نشان دهد.

اگر تصویر Hero انتخاب شده باشد:

با کلیک روی تصویر، همان Image Element انتخاب شود و کاربر بتواند:

- تصویر را تغییر دهد
- تصویر را حذف کند
- تصویر جدید از Media Library انتخاب کند
- Alt Text تنظیم کند
- Link بدهد
- اندازه را تغییر دهد
- Position را تغییر دهد
- Border Radius تغییر دهد
- Shadow تغییر دهد
- Responsive تنظیم کند

و تغییر باید بلافاصله در Preview دیده شود.

16. افزونه‌های WooCommerce باید بتوانند Widget اضافه کنند

این قسمت بسیار مهم است.

مثلاً:

```text
WooCommerce Plugin
↓
Elementor Widget
↓
Custom Product Widget

```

Aria Builder باید معماری Extensible داشته باشد تا Pluginها بتوانند برای Aria Builder نیز Widget ثبت کنند.

مثلاً API فرضی:

```php
aria_register_widget(...)

```

یا یک سیستم مشابه استاندارد طراحی کن.

هر Plugin بتواند:

```text
Plugin
↓

↓
Content Controls
↓
Style Controls
↓
Advanced Controls

```

اضافه کند.
